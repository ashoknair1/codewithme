# Ep 2 (Beginner) — The AI SDLC in 6 Stages — With a Real Project

**What you build:** the lifecycle map for MiniCRM — the six stages (Plan, Design, Build, Test, Deploy, Maintain), what document each stage produces, who owns it (you or the agent), and the exit test that lets work move on.

**The one key idea:** agents made Build nearly free, so the lifecycle didn't disappear — the human weight moved to the stages around it: planning, design judgment, testing, and maintenance accountability.

**Worth knowing:**
- A stage without an exit test is a vibe, not a stage. "Tests pass" is an exit test; "looks done" is not.
- Design is where you spend the judgment you saved on typing: data shapes and screen flows are cheap to change on paper, expensive in code.
- Maintain is the longest stage and the one demos skip — budget for it from day one.

**Try this:** take any project you've vibe-coded and write its six-stage map honestly — which stages did you skip entirely? Hint: the skipped stage is where your next bug is already living.
