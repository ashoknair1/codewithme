# The five levels of coding-agent adoption (Ep 6) — an original framing for this series

1. **Assisted** — autocomplete and chat answers; you still write nearly every line. Skill: good questions.
2. **Directed** — you hand an agent whole tasks against a brief (Series 02, Ep 1–2). Skill: precise specs.
3. **Harnessed** — your agent works inside tests, hooks and CI you built (Ep 3). Skill: designing checks, reading tests.
4. **Parallel** — multiple agents in roles ship features while you merge and review (Ep 4). Skill: splitting work, judging diffs.
5. **Accountable owner** — you run the full lifecycle for a team: standards, security, process (Eps 5–6). Skill: taste, accountability, teaching the levels below you.

The pattern: each level trades typing for judgment. Nobody skips levels — a level-5 process on level-2 habits produces fast, well-organized messes.
