# Ep 6 (Expert) — Ship It and Level Up: Deploy + The AI-Native Career Map

**What you build:** MiniCRM, deployed — one-command start, pinned dependencies, data file backed up, README a stranger can follow. Then the honest career frame: the five levels of coding-agent adoption, and what moving up them actually looks like in a job.

**The one key idea:** shipping is a checklist (see `deploy_checklist.md`), and so is leveling up. The engineers employers now compete for aren't the fastest typists — they're the ones who direct agents through the whole lifecycle and stand behind the result.

**Worth knowing:**
- Deploy day surprises are almost all environment, not code: versions, paths, the data file. The checklist exists because willpower doesn't scale.
- Adoption levels aren't tool collections — each level is a *responsibility* change: from accepting suggestions, to directing builds, to owning a harness, to running parallel agents, to setting the process a team follows.
- "AI-native" in a job post means: can this person be accountable for agent-produced work? Everything in this series is evidence for that interview.

**Try this:** score yourself against `adoption_levels.md` and pick the *next* level's one habit to practice this week. Hint: if you can't name your harness, you're not at level 3 yet — Ep 3 is your episode.
