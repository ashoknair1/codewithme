# INTENT — MiniCRM (Ep 1)

I run a tiny services business and my "CRM" is a spreadsheet I keep forgetting to update. I want a small program that tracks my contacts and my sales deals as a simple pipeline — lead, qualified, proposal, won, lost — so that in ten seconds I can see who I know, what might close, and what each stage is worth. It must run entirely on my own machine with my data in a plain file I can back up, because client names and deal values are nobody else's business.
