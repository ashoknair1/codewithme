# Ep 1 (Beginner) — Vibe Code Your First App with Claude Code

**What you build:** a working web app (a personal "link saver" page) from one plain-English brief — no code typed by hand.

**The one key idea:** the brief IS the code. A precise spec (what it does, what it must never do, how you'll know it works) beats clever prompting every time.

**Worth knowing:**
- Vague brief in → generic app out. Name the pages, the data, and the "done" test.
- Ask for ONE feature at a time after the first build; giant follow-up prompts tangle the code.
- Always ask Claude to *run the app and show you it working* before you accept the result.

**Try this:** take `app_brief.md`, change the app to a habit tracker, and build it. Hint: only the WHAT changes — keep the MUST NEVER and DONE WHEN sections exactly as strict.
