# Ep 2 (Beginner) — CLAUDE.md: The File That Makes Claude Code 10x Smarter

**What you build:** a CLAUDE.md for your project that Claude Code reads at the start of every session.

**The one key idea:** Claude forgets everything between sessions — CLAUDE.md is its memory. Project facts, commands, and rules live there once, not in every prompt.

**Worth knowing:**
- Short beats thorough: a 40-line CLAUDE.md gets followed; a 400-line one gets skimmed.
- Put *commands* in it (how to run, how to test) — that's what saves you the most typing.
- Rules you repeat twice in chat belong in the file the second time.

**Try this:** take the template here, fill it for a project you own, and count how many prompt sentences you stop typing. Hint: start with just the commands section — it's the highest-value 10 lines.
