# Generated sample PDFs live here (they are not committed to git)

Run the generator from the series folder:

```bash
cd ..           # project-series-01-pdf-toolkit/
python make_samples.py
```

It creates three **fictional** practice documents:

| File | Pages | Contents |
|---|---|---|
| `invoice.pdf` | 1 | A design-studio invoice for a fictional client |
| `receipts.pdf` | 2 | A grocery receipt and a transit-pass receipt |
| `rental_contract.pdf` | 4 | A four-section rental agreement between fictional people |

Merged in that order they make a 7-page document — the number the
series keeps checking against. All names, companies, addresses and
amounts are invented for this tutorial; any resemblance to real people
or businesses is a coincidence.

The big scanned contract used in Episode 4 lives in
`../ep04-intermediate-compress-rotate/samples/` and is generated by
that episode's `make_scan.py`.
